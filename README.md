# 🏥 Healthcare Analysis Dashboard

An interactive Power BI dashboard analyzing patient satisfaction across hospitals in the United States using Hospital Survey data.

--------------------------------------------------------------------------------------------------


# 📌 Project Overview

This project focuses on analyzing patient satisfaction trends across hospitals over multiple years.

The dashboard was designed to answer important business and healthcare questions related to:
- Patient satisfaction performance
- Measure improvements over time
- Regional and state-level comparisons
- Top-performing and low-performing healthcare measures

--------------------------------------------------------------------------------------------------


# 🎯 Project Goals

- Analyze patient satisfaction trends over time
- Compare Top Box vs Bottom Box performance
- Identify the best and worst-performing measures
- Explore healthcare performance across states and regions
- Detect measures with the highest improvement rates

--------------------------------------------------------------------------------------------------


# 🛠️ Tools Used

- Power BI
- Excel
- DAX
- Data Cleaning
- Data Visualization

--------------------------------------------------------------------------------------------------


# 📂 Dashboard Features

## 🟦 Executive Overview
Provides a high-level summary of healthcare performance.

### Includes:
- Total healthcare measures
- High improvement percentage
- Low improvement percentage
- Total states analyzed

--------------------------------------------------------------------------------------------------

## 📈 Trend Analysis
Analyzes patient satisfaction trends over time.

### Includes:
- Top Box Percentage trends
- Bottom Box Percentage trends
- Year-over-year performance comparison

### Key Insight:
Several healthcare measures showed continuous improvement in patient satisfaction across recent years.

--------------------------------------------------------------------------------------------------


## 📊 Performance Comparison
Compares healthcare measures against each other.

### Includes:
- Best-performing measures
- Lowest-performing measures
- Improvement comparison between measures

### Key Insight:
Communication and discharge-related measures consistently achieved higher satisfaction scores.

--------------------------------------------------------------------------------------------------


## 🌎 Regional & State Analysis
Breaks down healthcare performance geographically.

### Includes:
- State-level analysis
- Regional comparisons
- Measure performance by location

### Key Insight:
Patient satisfaction varies noticeably across regions and states, highlighting differences in healthcare service quality.
